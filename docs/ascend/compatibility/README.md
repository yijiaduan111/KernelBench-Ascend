# Ascend compatibility reports

Environment: Ascend 910B3, CANN 9.0.1, torch 2.7.1+cpu, torch_npu 2.7.1.post4.

The JSON files are generated by `scripts/audit_ascend_level.py`. Each problem is
run in an independent worker with a timeout.

The files in this directory record early Level 1 representative audits. The
authoritative corrected Level 1-3 suite is stored under
`ascend910b3-cann9.0.1/`: `supported.json` contains the 244 active tasks and
`excluded.json` contains the six diagnostic tasks. See
`../BASELINE_STATUS.md` for the audit protocol and interpretation.
