# Ascend Level 1 compatibility reports

Environment: Ascend 910B3, CANN 9.0.1, torch 2.7.1+cpu, torch_npu 2.7.1.post4.

The JSON files are generated by `scripts/audit_ascend_level.py`. Each problem is
run in an independent worker with a timeout. The reports currently cover the
10 representative problems (P1, P3, P5, P19, P23, P36, P47, P51, P89, P97).
P19 has both an initial short-timeout diagnostic and a completed supported run;
the completed run is the authoritative result.

This is a smoke/representative matrix, not yet the full 100-problem Level 1
matrix. Run the same auditor without `--problem-ids` to produce the full report.
